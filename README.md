# Personal Portfolio Website (Home & Contact)

A clean, responsive, and professional personal portfolio website built using **HTML5 and CSS3**. This project features a two-page layout designed to introduce myself and provide an easy way for visitors to get in touch.

## 🚀 Live Demo
You can view the live website here: **[link]**

## ✨ Features
* **Two-Page Architecture:** A clean separation between the main profile page and the communication page.
* **Home Page:** Features an introduction, background summary, and links to my professional work or skills.
* **Contact Page:** A dedicated space for potential employers, clients, or peers to reach out.
* **Responsive Design:** Optimized for seamless viewing on desktops, tablets, and smartphones.

## 🛠️ Technologies Used
* **HTML5:** Semantic markup structure across both pages.
* **CSS3:** Custom layout design, responsive media queries, and styling.

## 📁 Project Structure
```text
├── index.html          # Home/Landing page
├── contact.html        # Contact page
├── css/
│   └── style.css       # Core stylesheet shared across both pages
└── assets/
    └── images/         # Profile pictures, icons, or background graphics
```

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the folder:**
   ```bash
   cd your-repo-name
   ```
3. **Open the project:**
   Double-click `index.html` to view the website in your browser, or open the folder in your code editor.
